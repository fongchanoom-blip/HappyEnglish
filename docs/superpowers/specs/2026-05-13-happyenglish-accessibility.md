## 一、视觉可访问性

### 字体与排版

| 功能 | 设计方案 | 优先级 |
|------|---------|--------|
| 基础字号 | 正文不小于 16px，标题不小于 20px | 必须 |
| 字号调节 | 设置「小/中/大/特大」四档（12/16/20/24px） | 重要 |
| 行高比例 | 1.5-1.8 倍，避免密集文字 | 必须 |
| 字体选择 | 使用系统默认字体，避免花哨字体影响辨识 | 必须 |

### 颜色对比度

| 指标 | 标准值 | 实现方案 |
|------|--------|----------|
| 文本对比度 | ≥ 4.5:1（普通文本）| 禁止白底浅灰文字 |
| 深色模式 | 降低蓝光，支持系统跟随 | 独立主题切换 |
| 高对比度方案 | 文字与背景对比 ≥ 7:1 | 专为低视力用户设计 |

### 触控区域

| 规范 | 尺寸要求 | 目的 |
|------|---------|------|
| 最小触控区 | 44 × 44 像素 | 满足 WCAG 2.1 标准 |
| 按钮间距 | 相邻按钮间隔 ≥ 8px | 防止误触 |
| 进度指示 | 明确当前位置 | 帮助用户定位 |

## 二、听觉可访问性

### 音频辅助

```
已复用语音服务架构：
├── 本地音频播放（优先）
│   ├── 单词发音
│   ├── 例句朗读
│   └── 发音对比
│
└── 微信同声传译插件（备用）
    ├── 语音识别输入
    └── 语音合成朗读
```

### 字幕与文本

| 场景 | 解决方案 |
|------|----------|
| 单词发音 | 同步显示音标 [kæt]、中文释义 |
| 例句朗读 | 提供「隐藏式字幕」(CC) 可开关 |
| 拼读练习 | 实时显示用户发音的音标转换 |

### 音频控制

- 音量独立于系统音量
- 播放速度可调（0.75x / 1x / 1.25x）
- 重复播放按钮（听障用户可反复观看）
- 音频波形可视化（辅助确认播放状态）

## 三、认知可访问性

### 界面简化

```
学习模式分级：
├── 简洁模式
│   ├── 仅显示单词和释义
│   ├── 一键操作
│   └── 减少干扰元素
│
├── 标准模式（默认）
│   ├── 包含例句和练习
│   └── 适度引导
│
└── 增强模式
    ├── 语法解析
    ├── 词根词缀分析
    └── 详细解释
```

### 多语言支持

| 用户群体 | 界面语言 |
|---------|---------|
| 汉语用户 | 中文界面 |
| 少数民族学生 | 藏语/维吾尔语界面（逐步扩展） |
| 外籍学生 | 英文界面 |

## 四、网络与设备适配

### 弱网优化

| 策略 | 实现 |
|------|------|
| 离线缓存 | 预下载当前级别全部音频 |
| 按需加载 | 流量不足时仅加载文本 |
| 静默重试 | 网络抖动自动重试 3 次 |
| 降级方案 | 无网时显示已缓存内容 |

### 低配置设备支持

| 指标 | 目标值 |
|------|--------|
| 首次加载 | < 3 秒（2G 网络） |
| 内存占用 | < 50MB |
| 存储需求 | < 20MB |
| CPU 占用 | 低端机流畅运行 |

## 五、特殊教育需求支持

### 视觉障碍支持

| 功能 | 说明 |
|------|------|
| 屏幕阅读器兼容 | 所有元素添加 aria-label |
| 焦点导航 | 支持 Tab 键顺序访问 |
| 放大镜模式 | 双击文字放大显示 |
| 色盲模式 | 红绿区分改为蓝橙区分 |

### 听觉障碍支持

| 功能 | 说明 |
|------|------|
| 视觉反馈 | 发音时显示嘴型动画 |
| 振动提示 | 答对/答错时可开启振动 |
| 字幕始终显示 | 可设为默认开启 |
| 手语视频（远期） | 关键语法配手语演示 |

### 注意力障碍支持

| 功能 | 说明 |
|------|------|
| 单任务界面 | 一次只展示一个学习任务 |
| 计时提醒 | 25 分钟后休息提醒 |
| 减少动画 | 可关闭所有非必要动画 |
| 任务分解 | 大目标拆分为小步骤 |

### 运动障碍支持

| 功能 | 说明 |
|------|------|
| 语音操控 | 继承语音指令功能 |
| 单手模式 | 页面布局适配左手用户 |
| 大按钮 | 所有操作按钮 ≥ 60px |
| 手势简化 | 仅支持点击、长按 |

## 七、核心结论

**普惠教育的技术温度**：
- 每个人都想学好英语，无论能力高低
- 可访问性不是"额外功能"，而是"基本设计"
- 投入少量成本，服务更广泛用户群体
- 差异化设计（如双模式）让所有用户都舒适
