## 一、产品概述

### 1.1 产品定位

**HappyEnglish** 是一款面向中学生的英语单词记忆与测试系统，通过科学的记忆曲线算法和游戏化激励系统，帮助学生高效掌握英语词汇。

### 1.2 目标用户

- 主要用户：初中生（13-15岁）
- 用户数量：支持多学生，数据相互隔离
- 使用场景：课后自主学习、考前复习

### 1.3 核心价值

- 科学记忆：基于艾宾浩斯遗忘曲线，智能安排复习
- 游戏化激励：积分、徽章、段位、头像升级
- 针对性训练：掌握度分级，重点攻克薄弱词
- 离线可用：断网可学习，联网后自动同步

| 轮次完成 | 完成一轮 +200分 |
| 每日目标 | 完成20题 +30分，完成50题 +100分 |

## 三、掌握度系统

### 3.1 等级划分

| 等级 | 定义 | 测试频率 | 颜色 |
|------|------|----------|------|
| 精通 | 正确率 ≥90%，错误次数 ≤1 | 每2-3轮测1次 | 绿色 |
| 熟悉 | 正确率 70-89% | 每1-2轮测1次 | 蓝色 |
| 薄弱 | 正确率 40-69% | 每轮必测 | 黄色 |
| 陌生 | 正确率 <40% | 每次必测+单独复习 | 红色 |

### 3.2 热力词云设计

**布局：** 两栏并排对比
- 左侧（绿色系）：掌握好的50个词
- 右侧（红色系）：需要加强的50个词

**字体大小规则：**
- 错误越少，字体越大（绿色区）
- 错误越多，字体越大（红色区）
- 4级字体大小：44px → 32px → 24px → 18px/14px

**视觉要求：**
- 词与词不重叠，清晰排列
- 绿色系/红色系各50词
- 字体大小按错误次数递减

### 3.3 掌握度仪表盘

- 环形图显示各等级占比
- 轮次进度卡显示各轮完成度
- 进步曲线图展示提升趋势

## 八、技术架构

### 8.1 技术选型

| 层级 | 技术 | 选择理由 |
|------|------|----------|
| 前端 | 原生 HTML/JS/CSS | 开发快，代码简单 |
| 后端 | Supabase（免费） | 云数据库+用户认证 |
| 离线存储 | IndexedDB | 容量大，支持结构化数据 |
| 部署 | Vercel（免费） | 自动HTTPS，无限部署 |
| AI | Minimax API | 头像生成 |

### 8.2 免费资源额度

| 平台 | 免费额度 | 限制 |
|------|----------|------|
| Supabase | 5MB数据库，1万用户 | 超量后 $25/月 |
| Vercel | 无限次部署，100GB带宽 | 无其他限制 |
| Minimax | 按调用量计费 | 有免费额度 |

### 8.3 数据同步策略

- 用户数据优先存储本地（IndexedDB）
- 联网时自动同步到云端（Supabase）
- 冲突处理：本地优先，合并增量

## 设计评审决议（2026-05-12）

### 砍掉的设计

| 设计 | 原因 |
|------|------|
| 段位保护机制 | 增加复杂度，且有漏洞 |
| 限时挑战 | v2再做 |
| 段位赛 | v2再做 |
| AI头像生成 | 技术风险+内容审核风险太高 |

### 修改的设计

| 问题 | 修改方案 |
|------|----------|
| 热力词云显示数量 | 改为"显示最近测试过的词"，数量动态（至少10个） |
| 激励过于游戏化 | 减少奖励频率，增加学习效果权重 |
| 家长监督缺失 | 添加简单的学习报告（不需要专门家长端） |
| 挫败感问题 | 绿色区为空时显示鼓励语，不显示空状态 |

### 最终MVP范围

| 优先级 | 功能 |
|--------|------|
| P0 | 标准测试 + 掌握度四级 + 热力词云（动态） |
| P0 | 积分 + 徽章 + 等级系统 |
| P0 | 连续答题连击奖励 |
| P1 | 轮次进度管理 |
| P1 | 错题复习 + 导出 |
| P1 | 简单学习报告 |
| P2 | 段位系统（简化版，无段位保护） |
| P2 | 预设头像升级（非AI生成） |
| P3 | 限时挑战、段位赛、AI头像 |
