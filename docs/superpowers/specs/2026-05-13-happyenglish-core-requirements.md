# HappyEnglish 核心功能需求文档

> 日期：2026-05-13
> 核心功能：帮助中学生加强单词库内的单词记忆
> 需求来源：11场头脑风暴会议、20+专家观点、4轮用户调研

---

## 一、需求概览

### 核心问题
**学生记不住单词** —— 这是所有需求的核心出发点

| 问题维度 | 具体表现 | 影响 |
|---------|---------|------|
| 遗忘规律 | 背了忘、忘了背 | 学习效率低 |
| 缺乏语境 | 孤立记忆、无法应用 | 理解浅、用法错 |
| 重复无效 | 同样的复习无效 | 挫败感强 |
| 被动学习 | 只看不练、输入不足 | 记忆不深 |

### 核心解决思路

```
目标：让单词从"见过"变成"记住"

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   记忆 = 输入（多感官） + 理解（语境） + 输出（主动回忆）    │
│                                                             │
│   AI 的作用：                                               │
│   - 个性化语境生成（让每个词都有故事）                      │
│   - 智能复习时机（在你快忘的时候提醒）                      │
│   - 即时反馈（告诉你哪里错了、为什么）                      │
│   - 苏格拉底引导（让你自己发现答案）                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、功能需求

### P0 必须做（直接影响记忆效果）

#### 2.1 语境记忆生成

**问题**：单词孤立记忆，缺乏语境关联

**需求描述**：
- AI 根据单词生成生活化场景故事（100-200字）
- 故事包含：中文场景 + 英文例句 + 记忆锚点
- 支持按主题（学校/家庭/运动等）生成关联故事
- 支持按错误模式生成纠正性故事

**技术要求**：
- 调用 LLM 生成内容，缓存复用
- 支持批量预生成（离线时）
- 故事内容需与学生年级匹配

**验收标准**：
- 单词在故事中出现时记忆效果 > 40%（对比无故事）
- 故事生成延迟 < 3秒
- 可离线查看已生成故事

---

#### 2.2 智能错题讲解

**问题**：答错了不知道错在哪，只知道"不对"

**需求描述**：
- 答错时弹出 AI 讲解卡片
- 讲解内容：词义辨析、常见错误、正确用法
- 支持追问（学生可继续提问）
- 记录错误类型，下次自动加强

**技术要求**：
- 基于错误词和正确词生成讲解
- 支持多轮对话延续
- 错误模式分类存储

**验收标准**：
- 讲解内容准确率 > 95%
- 用户追问率 > 30%（说明有用）
- 相似错误重复率下降 > 50%

---

#### 2.3 间隔重复复习

**问题**：复习时机不对，要么太早要么太晚

**需求描述**：
- 基于艾宾浩斯遗忘曲线 + 个人错误模式动态计算复习时机
- 当学生"快忘记"时触发复习提醒
- 复习内容优先：高频错词 > 低频错词 > 新学词
- 支持自定义复习目标（每日/每周）

**技术要求**：
- 本地计算复习间隔（不依赖网络）
- 记录每次记忆强度变化
- 支持多设备同步（可选）

**验收标准**：
- 复习提醒准确度 > 80%（在遗忘点前）
- 复习后记忆保留率 > 70%（对比不复习）
- 间隔计算误差 < 1天

---

### P1 重要（显著提升体验）

#### 2.4 学习报告

**问题**：不知道自己学得怎么样，没有方向

**需求描述**：
- 每日/每周生成 AI 学习报告
- 内容：掌握度变化、薄弱词分析、学习建议
- 支持可视化图表展示趋势
- 可分享给家长（展示学习成果）

**技术要求**：
- 基于学习数据自动生成
- 支持推送通知（可选）
- 报告结构化存储

**验收标准**：
- 报告覆盖 90% 以上学习数据
- 生成延迟 < 5秒
- 用户查看率 > 50%

---

#### 2.5 发音分析与纠正

**问题**：只知道拼写，不知道发音对不对

**需求描述**：
- 学生录音后可获得发音评分
- 显示音素错误（具体到哪个音）
- 提供正确发音示范
- 支持跟读练习模式

**技术要求**：
- 调用语音识别 API
- 本地缓存音频文件
- 支持离线评分（轻度场景）

**验收标准**：
- 评分与专家判断一致率 > 85%
- 反馈延迟 < 2秒
- 支持主流单词发音覆盖

---

#### 2.6 多感官学习

**问题**：只靠眼睛看，记忆不够深

**需求描述**：
- 单词学习时：视觉（例句）+ 听觉（发音）+ 触觉（手写）
- 支持拼写练习（输入回忆）
- 支持听音选词（听觉回忆）
- 多种学习模式自由切换

**技术要求**：
- 支持键盘输入、手写识别（可选）
- 题目随机生成
- 正确/错误即时反馈

**验收标准**：
- 支持至少 3 种学习模式
- 每种模式正确率统计完整
- 切换模式无数据丢失

---

### P2 增强（锦上添花）

#### 2.7 词根词缀分析

**问题**：记一个是一个，不会举一反三

**需求描述**：
- 显示单词的词根/词缀解释
- 关联同根词展示
- 帮助学生构建词汇网络

**验收标准**：
- 覆盖 60% 核心词汇词根
- 关联词展示 > 3个

---

#### 2.8 学习伙伴（Agent 雏形）

**问题**：学习枯燥，容易放弃

**需求描述**：
- AI 学习伙伴角色（可以叫名字）
- 会在适当时候鼓励、提醒、庆祝
- 记住学生的喜好和进度
- 支持简单对话（"这个词怎么记？"）

**技术要求**：
- 记忆系统存储学生画像
- 对话引擎响应简单问题
- 里程碑事件触发庆祝

**验收标准**：
- 学生愿意和 AI 对话
- 学习动力提升可量化

## 三、技术需求

### 3.1 记忆系统

**核心需求**：记录学生学习状态，实现个性化

```
┌─────────────────────────────────────────────────────────────┐
│                    学生学习画像                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  单词掌握度：Map<word, {known, recall, lastReview}>        │
│                                                             │
│  错误模式：List<{type, word, count, lastError}>            │
│                                                             │
│  学习行为：{preferredTime, sessionCount, streakDays}       │
│                                                             │
│  学习偏好：{modality, difficulty, explanationStyle}         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**存储要求**：
- 本地 IndexedDB 存储
- 支持云端同步（可选）
- 隐私合规（家长授权）

---

### 3.2 AI 服务

**核心需求**：低成本、高质量、响应快

| 场景 | 模型选择 | 延迟目标 |
|------|---------|---------|
| 语境故事生成 | Deep Model | < 3s |
| 错题讲解 | Deep Model | < 2s |
| 简单问答 | Fast Model | < 500ms |
| 发音评分 | Fast Model | < 1s |

**降级策略**：
- AI 服务不可用时使用预置模板
- 缓存已生成内容复用
- 支持离线使用（基础功能）

---

### 3.3 数据分析

**核心需求**：了解学生真实学习状态

**必须记录**：
- 每次学习：单词、耗时、结果
- 每次复习：间隔、正确率变化
- 每次错误：错因、后续是否纠正

**分析输出**：
- 掌握度曲线
- 薄弱词列表
- 学习效率趋势

## 四、用户体验需求

### 4.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 首次打开 | < 3秒 |
| 再次打开 | < 1秒 |
| 操作响应 | < 100ms |
| AI 内容加载 | < 5秒 |

### 4.2 离线能力

- 核心功能（背单词、测试、复习）必须离线可用
- AI 报告、语境生成需要网络
- 已生成内容支持离线查看

### 4.3 学习体验

- 单次学习时长：建议 10-15 分钟
- 每日学习目标：可自定义
- 休息提醒：每 25 分钟提示
- 成就系统：里程碑展示、庆祝动画

## 七、实施建议

### 第一阶段（MVP）：核心记忆闭环

**目标**：验证"AI 语境 + 智能复习"能提升记忆效果

**功能范围**：
1. 语境记忆生成（每日故事）
2. 间隔重复复习（智能提醒）
3. 简单学习报告（周报）

**验证指标**：
- 记忆效果对比（AI语境 vs 无语境）
- 复习提醒准确度
- 用户留存率变化

### 第二阶段：体验增强

**目标**：丰富学习方式，提升体验

**功能范围**：
1. 智能错题讲解
2. 发音分析纠正
3. 多感官学习模式

### 第三阶段：智能体进化

**目标**：从工具到伙伴的跃迁

**功能范围**：
1. 学习伙伴角色
2. 长期记忆与情感连接
3. 主动学习引导

## 八、关键成功因素

基于头脑风暴共识，以下是影响项目成功的关键：

1. **记忆效果可验证**：学生必须能感受到"真的记住了"，这是核心价值
2. **AI 质量控制**：讲解必须准确，不能误导学生
3. **不过度依赖**：AI 是辅助，不是替代学生思考
4. **数据隐私**：儿童数据必须严格保护
5. **持续迭代**：基于真实使用数据优化，而非假设
