## 一、用户旅程设计

### 用户 A：初三学生（冲刺中考）

```
┌─────────────────────────────────────────────────────────────────┐
│                        每日学习旅程                              │
├─────────────────────────────────────────────────────────────────┤
│  起床/通勤 (3分钟) → 快速复习：3-5个易错词 + AI薄弱点提醒       │
```

## 二、双模式视觉风格

### 冲刺模式（初三学生）

| 维度 | 设计选择 | 理由 |
|------|---------|------|
| **配色** | 深蓝 + 白灰背景 + 橙色强调 | 冷静专业，减少视觉疲劳 |
| **字体** | 思源黑体（标题）/ DIN（数字） | 清晰易读 |
| **布局** | 大量留白，单卡片布局 | 减少干扰，聚焦内容 |
| **图标** | 线性图标 + 统一描边宽度 | 清晰不抢眼 |

```css
/* 冲刺模式 色彩系统 */
:root {
  --primary: #1a365d;      /* 深蓝 - 专业感 */
  --background: #f8fafc;    /* 浅灰白 - 干净 */
  --accent: #ed8936;        /* 橙色 - CTA/进度 */
}
```

### 冒险模式（小学低年级）

| 维度 | 设计选择 | 理由 |
|------|---------|------|
| **配色** | 明亮渐变（蓝→粉）+ 黄色高光 | 活泼有朝气 |
| **字体** | 圆体/童趣字体 + 大号按钮文字 | 亲和力强 |
| **布局** | 圆角卡片 + 角色插画 + 装饰元素 | 可爱友好 |
| **图标** | 填充式图标 + 表情符号风格 | 直观有趣 |

```css
/* 冒险模式 色彩系统 */
:root {
  --primary: #667eea;      /* 紫色渐变起点 */
  --secondary: #f687b3;      /* 粉色 */
  --accent: #fbd38d;        /* 暖黄色高光 */
  --background: #fffbf0;    /* 米黄暖调 */
}
```

## 五、主题切换机制

```
用户首次使用时选择「使用场景」：
- [ ] 我在准备中考（自动启用冲刺模式）
- [ ] 我在上小学（自动启用冒险模式）

设置中可随时切换：
[设置] → [界面风格] → ○冲刺模式 ○冒险模式
```

## 六、核心设计原则

1. **场景优先**：根据用户类型自动适配，而非让用户适应产品
2. **效率为王**（初中）：减少点击次数，一屏展示关键信息
3. **趣味为王**（小学）：奖励驱动，正向反馈循环
4. **数据透明**：学习进度、薄弱点清晰可见，建立信任感
5. **平滑过渡**：用户可在设置中切换模式，体验连贯

---

## 七、记忆点设计

> 让用户记住的不是某个功能，而是使用时的"感觉"
> - 初中生："这个工具很快，没有废话"
> - 小学生："小星是我的好朋友，我们一起学英语"
