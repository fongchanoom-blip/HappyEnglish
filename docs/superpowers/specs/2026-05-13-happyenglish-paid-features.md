## 一、免费用户功能边界

**核心目标**：让用户感受到价值，但不足以满足"提分"需求

| 功能 | 免费版 | 目的 |
|------|--------|------|
| 单词学习（核心词库） | 限 300 词 | 建立基础体验 |
| 基础测试 | 每日 10 题 | 验证学习效果 |
| AI 学习报告（基础版） | 每周 1 份 | 展示数据价值 |
| 学习进度追踪 | 基础指标 | 培养使用习惯 |
| 成就徽章系统 | 限前 10 个 | 建立成就感 |

**边界设计原则**：免费功能足够好，但无法支撑"中考提分"这一核心需求

## 五、家长付费决策心理

```
                    家长决策漏斗
                         │
                         ▼
              ┌─────────────────┐
              │   中考焦虑驱动    │ ← 时间压力（只剩 X 月）
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   教育投资回报    │ ← 提分效果预期
              │   感知可信度      │   ROI 计算
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   沉没成本效应    │ ← 孩子已使用一段时间
              │   (已投入)        │   放弃 = 前功尽弃
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   同伴压力效应    │ ← "其他家长都在用"
              └────────┬────────┘
                       │
                       ▼
                  【购买决策】
```

### 针对家长的营销策略

| 痛点 | 营销文案 | 落地页元素 |
|------|----------|------------|
| **没时间监督** | "孩子学习你看得见，每周报告送到手" | 家长端截图 + 数据可视化 |
| **不知道效果** | "用数据说话：30 天提升正确率 20%" | 真实用户案例 + 对比图 |
| **担心孩子坚持不了** | "AI 动态调整，孩子每天只需 15 分钟" | 学习路径图 + 时长承诺 |
| **价格敏感** | "每天不到 1 元，中考多拿 20 分" | 性价比计算器 |
| **怕白花钱** | "7 天无理由退款，效果不满意退全款" | 退款保障标识 |

## 六、核心结论

### 付费功能体系全景图

```
                    ┌─────────────────┐
                    │   家长愿意付钱   │
                    │   (购买者体验)   │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
     ┌────────────┐  ┌────────────┐  ┌────────────┐
     │ 成绩提升   │  │ 时间节省   │  │ 焦虑缓解   │
     │ 可感知     │  │ 可量化     │  │ 有保障     │
     └─────┬──────┘  └─────┬──────┘  └─────┬──────┘
           │               │               │
           └───────────────┼───────────────┘
                           │
                           ▼
              ┌─────────────────────┐
              │   HappyEnglish      │
              │   VIP 价值体系       │
              └─────────────────────┘
```

### 关键执行建议

1. **免费版必须足够好**：让用户体验到"这个 app 真的有用"
2. **付费触发要自然**：在学习遇到瓶颈时推送，不要强行弹窗
3. **家长端是关键**：中国家长是决策者，给他们看得到的数据
4. **设置退款门槛**：7 天无理由退款，大幅降低首单阻力
5. **年度套餐为主推**：提高 LTV（用户生命周期价值）
