## 3. 词汇学习

点击底部导航栏的**「词汇学习」**进入词汇页面。

### 3.1 词汇掌握度

词汇按掌握程度分为 4 个等级：

| 等级 | 颜色 | 标准 |
|------|------|------|
| 精通 | 🟢 绿色 | 正确率 ≥90%，错误 ≤1 次 |
| 熟悉 | 🔵 蓝色 | 正确率 ≥70% |
| 薄弱 | 🟡 黄色 | 正确率 ≥40% |
| 陌生 | 🔴 红色 | 未测试或正确率 <40% |

### 3.2 词云展示

页面下方显示词云图：
- 字号越大 = 错误越少 = 掌握越好
- 点击任意词汇可进入该词的测试

![词汇页面](./screenshots/02_vocabulary_cloud.png)

## 4. 批量测试

### 4.1 进入批量测试

在首页点击**「批量测试」**按钮。

### 4.2 测试界面

```
┌─────────────────────────────────┐
│  第 1 组 · 共 160 组词汇        │
├─────────────────────────────────┤
│  1  一(个、件……)   [输入框]    │
│  2  能力；才能     [输入框]     │
│  3  能够；有才能的 [输入框]     │
│  ...                             │
├─────────────────────────────────┤
│  [返回首页]      [下一组 →]     │
└─────────────────────────────────┘
```

### 4.3 操作步骤

1. 页面显示 10 个中文释义
2. 在输入框中输入对应的英语单词
3. 点击**「下一组」**继续
4. 完成 3 组后显示测试结果

## 5. AI 学习报告

### 5.1 配置 API Key（首次使用）

点击**「生成 AI 学习报告」**按钮，首次使用时需要配置 MiniMax API Key。

![API Key 配置](./screenshots/06_ai_report_input.png)

**获取 API Key：**

1. 访问 [MiniMax 开放平台](https://www.minimax.io/)
2. 注册/登录账号
3. 创建 API Key
4. 复制 Key 并粘贴到输入框
5. 点击**「保存并生成报告」**

### 5.2 查看报告

API Key 配置完成后，点击「生成 AI 学习报告」可查看：

| 报告部分 | 说明 |
|----------|------|
| 📊 学习概览 | 整体学习情况评价 |
| 🔥 学习趋势 | 正确率和进步情况 |
| 💡 AI 分析 | 薄弱词分析和记忆建议 |
| 🎯 下周目标 | 具体可行的学习目标 |
| 🏆 激励语 | 鼓励语句 |

### 5.3 安全说明

- API Key 使用 **localStorage** 持久化存储
- 关闭浏览器后 Key 仍会保留
- 如需清除，请手动清除浏览器缓存

### 6.1 积分规则

| 行为 | 积分 |

| 答对陌生词 | +30分 |
| 答对薄弱词 | +20分 |
| 答对熟悉词 | +10分 |
| 答对精通词 | +5分 |
| 10 连击 | +50分 |

### 6.2 等级系统

- **等级计算**：每 100 分升 1 级

## 7. 常见问题

### Q1：批量测试显示"请先完成前面的关卡"？

这是游戏关卡解锁机制。需要先在**「测试」**页面通过前面的关卡，才能解锁后续关卡。游戏关卡按词汇顺序设计。

### Q2：AI 学习报告无法生成？

1. 检查是否已配置 API Key
2. 确认 API Key 有效
3. 检查网络连接

### Q3：如何清除已保存的 API Key？

在浏览器控制台执行：
```javascript
localStorage.removeItem('minimax_api_key')
```

### Q4：数据保存在哪里？

所有学习进度保存在浏览器 **IndexedDB** 中：
- 路径：本地浏览器存储
- 不会上传到服务器
- 清除浏览器缓存会丢失数据
