## 六、软件用途

本软件面向 3-12 岁儿童、初中生及英语学习者，提供基于认知科学和人工智能的英语单词学习与训练。

传统背单词软件普遍存在三大痛点：(1) 复习节奏采用固定时间表（如艾宾浩斯 1/2/4/7/15 天），未考虑个人记忆差异；(2) 错题归因粗糙（仅区分"对/错"），无法识别拼写错误、语义错误、语音错误、语法错误四类认知错误的记忆强度衰减差异；(3) 学习反馈滞后，缺乏场景化触发（如连错 2 题主动降低难度并展示词根），导致用户学习动机下降。

HappyEnglish 围绕这三大痛点实现差异化能力：

- 自研基于 SM-2 间隔重复算法的"分类型错误权重"记忆模型，区别于 Anki 等通用闪卡工具，将四类认知错误映射为不同记忆强度衰减系数，使复习节奏贴合个人记忆曲线；
- 内置基于规则与统计混合的"场景触发引擎"，根据用户实时答题情况（连对/连错/超时/卡顿）自动触发教学干预（降低难度、显示词根、推送强化练习、启动语音复习），实现主动式学习引导；
- 自研"学习伴侣（LearningCompanion）"组件，使用 Vue 3 组件 + IndexedDB 持久化 + 等级/经验/连击系统，将抽象的学习进度具象化为可视化的成长曲线，提升儿童用户的学习动机与留存。

本软件适用于家庭自主学习、学校课后复习、出国考试备考（KET/PET/雅思/托福词汇基础）等多类使用场景，兼容主流现代浏览器，可在 PC、平板、手机等设备上运行。

## 七、技术特点

HappyEnglish 在技术架构和工程实现上具有以下独创性特点：

### （一）算法与模型层

**1.【P0-1】基于 SM-2 的分类型错误权重间隔重复算法**

本软件自主实现了基于 SuperMemo 2（SM-2）算法的间隔重复引擎（src/js/spaced-repetition.js，第 6 行 SpacedRepetitionEngine 类，第 26 行 calculateMemoryStrength 方法），并针对英语学习的认知错误特征进行扩展。通用 SM-2 算法仅根据"对/错"二元反馈调整记忆强度，本软件创新性地将错误划分为拼写错误（spelling）、语义错误（meaning）、语音错误（phonetic）、语法错误（grammar）四类，并为每类错误赋予不同的记忆强度衰减权重（分别为 15/10/8/5），从而更精细地建模用户记忆衰减规律。

**2.【P1-11】面向 K12 英语的 1594 词结构化词库 Schema**

本软件自研了包含 1594 词的结构化词库 Schema（src/data/vocabulary_full.js，第 1619 行），每个词条包含 examPoints（考点分布）、difficulty（难度分级）、rootAffix（词根词缀）等十余个字段，区别于通用 CSV 词表，支持考点驱动的精准推送。

**3.【P1-6】词根词缀引擎**

src/js/etymology.js（第 114 行）实现了基于词根词缀的"举一反三"记忆法，可根据词族关系自动推荐相关词（如学习 "act" 时自动推送 "action / active / actor"），辅助用户建立词汇网络。

### （二）交互与触发层

**4.【P0-2】场景触发引擎**

本软件自研了基于规则引擎 + 统计触发的混合触发引擎（src/js/trigger-engine.js 第 28 行 TriggerEngine 类），支持多场景（连续答对 3 题奖励升级、连续答错 2 题降低难度并展示词根、超时未答题切换语音复习、连续 7 天未学习发送激励卡片等）的实时触发。区别于通用规则引擎，本触发引擎的事件源既包括用户答题事件，也包括 IndexedDB 中历史错题统计和实时时间窗口。

**5.【P0-3】学习伴侣与数字人**

本软件自研了 LearningCompanion 类（src/js/learning-companion.js 第 5 行）与 CompanionWidget 组件（src/components/companion-widget.js 第 5 行），将学习状态抽象为"养成型数字人"，具有名称、等级、经验值、心情、连击天数 5 个核心属性。区别于通用"虚拟宠物"组件，本组件通过事件总线（on/off/emit）与触发引擎解耦，并通过动态注入 CSS 实现气泡位置和动画的自适应。

**6.【P0-4】成就系统**

src/js/achievement-system.js 第 293 行 AchievementSystem 类实现了多状态（Locked / InProgress / Unlocked / Claimed）成就系统，包含学习天数、单词量、连击、特殊成就四大类共 30 余项成就。区别于通用徽章系统，本系统支持成就进度追踪（如"已学 7/10 天"）、关联奖励自动发放、成就墙可视化。

### （三）数据与服务层

**7.【P0-5】基于 MCP 协议的 AI 调用封装**

本软件自主实现了基于 Model Context Protocol（MCP）的 MiniMax API 调用封装（mcp-server/minimax-server.js 第 33 行 tools/list 处理器），使 Claude Code 等 AI 工具可通过标准 MCP 协议调用本软件内置的 AI 能力。同时配套实现 Vercel Edge Function（api/ai-report.js 第 125 行 buildReportPrompt）用于生成个性化 AI 学习报告，结合教育心理学提示词工程（词根分析 + 记忆曲线 + 激励语）。

**8.【P0-6】个性化推荐引擎**

src/js/personalized-suggestions.js 第 5 行 PersonalizedSuggestions 类实现了基于用户记忆档案（强项词/弱项词/学习时段偏好）的个性化推荐算法，结合触发引擎输出推荐建议（如"上午 9 点推荐 5 个薄弱词 + 2 个新词"）。

**9.【P1-1】IndexedDB 多存储事务封装**

src/js/db.js（第 616 行）实现了 IndexedDB 的多 objectStore 事务封装，支持 masteries（记忆状态）/ wordHistory（答题历史）/ achievements（成就状态）/ userProfile（用户档案）的并发读写。

**10.【P1-2】记忆档案建模**

src/js/memory-profile.js（第 337 行）构建了用户记忆画像（强项词/弱项词/学习时段/记忆持久度），作为个性化推荐的输入。

### （四）工程与体验层

**11.【P1-4】奖励系统**

src/js/rewards.js（第 197 行）实现学习奖励发放逻辑，包括金币、经验值、连击奖励等，与成就系统和学习伴侣深度联动。

**12.【P1-5】等级与权限系统**

src/js/level.js（第 11 行 calculateWordLevel 函数）实现基于单词学习进度的等级计算，区分已掌握 / 掌握中 / 薄弱 / 陌生四档。

**13.【P1-7】hash 路由**

src/js/router.js（第 20 行 Router 类），实现纯前端 SPA hashchange 路由，支持参数化路径与守卫。

**14.【P1-8】响应式状态管理**

src/js/store.js（第 13 行 userState 对象）实现 class-based 响应式状态管理，通过 Proxy 监听变更并通知订阅者。

**15.【P1-9】语音服务**

src/services/speech.js（第 349 行）集成 Web Speech API 实现英语单词朗读、语音识别评测，支撑听说训练场景。

**16.【P1-10】AI 服务统一封装**

src/js/ai-service.js（第 444 行）统一处理 token 限流、错误重试、降级策略，为上层调用方屏蔽 AI 服务细节。

**17.【P1-12】30 题批量测试**

src/pages/review.html（第 1522 行）实现"3 组 × 10 题"的分组测试模式，每组测试结束后给出小结与推荐复习计划。

**18.【P1-3】错题根因 AI 分析**

基于 api/ai-report.js 的教育心理学 prompt 工程，对错题进行根因归因（拼写 / 语义 / 语音 / 语法），输出针对性复习建议。
