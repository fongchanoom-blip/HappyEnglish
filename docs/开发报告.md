## 一、项目概述

**HappyEnglish** 是一款专为初中生中考英语备考设计的微信小程序，核心理念是"高效备考，轻松提分"。

### 1.1 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vue 3 | 渐进式 JavaScript 框架 |
| 本地存储 | IndexedDB | 结构化数据持久化 |
| AI 服务 | MiniMax API | 生成语境故事、错题分析 |
| 部署平台 | Netlify | 自动部署 |

## 三、核心模块详解

### 3.1 数据库层（db.js）

**功能：** IndexedDB 封装，管理所有本地数据

**数据表：**
| 表名 | 用途 | KeyPath |
|------|------|---------|
| progress | 单词学习进度 | wordId |
| memory | 记忆系统数据 | wordId |
| stories | AI 故事缓存 | wordId |
| errors | 错误记录 | id (autoIncrement) |
| errorAnalysis | 错题分析缓存 | id |
| stats | 用户统计 | id |
| settings | 系统设置 | key |

**核心方法：**
- `saveMastery()` - 保存单词掌握度
- `saveErrorAnalysis()` - 保存错题分析
- `getErrorPatterns()` - 获取错误模式
- `getAllErrorAnalysis()` - 获取所有错题分析

### 3.2 AI 服务层（ai-service.js）

**功能：** 封装 MiniMax API 调用

**核心方法：**
```javascript
// 生成语境故事
async generateContextStory(word, context)

// 生成错题分析
async generateErrorAnalysis(word, wrongAnswer, correctAnswer)

// 生成学习报告
async generateReport(stats)
```

**缓存策略：**
- 内存缓存（Map，LRU，100条上限）
- 24小时过期

### 3.3 间隔重复引擎（spaced-repetition.js）

**算法：** 基于艾宾浩斯遗忘曲线 + SM-2 改进

**核心方法：**
```javascript
// 计算下次复习间隔
calculateInterval(mastery, result)

// 计算优先级
calculatePriority(wordId, mastery, errorTypes)

// 获取待复习单词
getWordsForReview(progress, limit, errorPatterns)

// 计算记忆强度
calculateMemoryStrength(mastery)
```

**状态流转：**
```
陌生 → 薄弱 → 掌握中 → 已掌握
  ↓        ↓        ↓
(错误)   (进步)   (连续5次)
```

### 3.4 错题本（review.html）

**功能：** 错题分类、AI分析、掌握追踪

**界面模块：**
1. **分类侧边栏** - 全部/拼写/词义/发音/语法
2. **错题卡片** - 单词、错误答案、正确答案、状态
3. **详情弹窗** - AI分析内容、掌握进度
4. **专项练习** - 同类错误单词练习
