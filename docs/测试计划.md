## 三、执行计划

### 3.1 测试执行顺序

```
Step 1: 环境验证
  └─ 服务器启动、页面可访问

Step 2: 冒烟测试 (5分钟)
  ├─ 首页加载
  ├─ 主要入口可点击
  └─ 无JS致命错误

Step 3: 核心功能测试 (15分钟)
  ├─ 批量测试完整流程
  ├─ 复习模块交互
  └─ 错题本功能

Step 4: AI服务测试 (5分钟)
  ├─ API连接测试
  └─ 故事生成测试

Step 5: 回归测试 (5分钟)
  └─ 验证修复的问题
```

### 3.2 测试数据

**测试词汇：** 使用实际词汇表中的单词
**测试数量：** 每组30题 × 3组
**错题模拟：** 故意选错2-3题
