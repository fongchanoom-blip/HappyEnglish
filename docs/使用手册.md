# 🧠 5. 智能复习

## 5.1 为什么需要智能复习？

> 🧠 **遗忘曲线**告诉我们：学习后不复习，1天后忘记67%，1周后忘记90%！

```
遗忘曲线 vs 复习效果
────────────────────────────────────────────────────────

记住所学  │
100% │    ╭╮                    ← 只学习，不复习
 80% │   ╱  ╲                   ← 第1天就忘了大半
 60% │  ╱    ╲
 40% │ ╱      ╲
 20% │╱        ╲____
  0% │              ╲___________→ 时间
      1天  3天  7天  14天 30天


100% │    ╭─╮
 80% │   ╱    ╲──╮
 60% │  │       ╲ ╲──╮       ← 及时复习，保持记忆
 40% │  │         ╲   ╲──╮
 20% │  │           ╲     ╲──╮→ 长期记忆
  0% │
      复习点: 1天→3天→7天→14天→30天
```

## 5.2 艾宾浩斯复习间隔

| 复习次数 | 最佳复习时间 | 记忆效果 |

| 第3次 | 第2次后**7天** | 📝📝📝 |
| 第4次 | 第3次后**14天** | 📝📝📝📝 |

# ❓ 8. 常见问题

## 8.1 数据相关

| 问题 | 解答 |
|------|------|
| 📁 **学习数据保存在哪？** | 保存在浏览器IndexedDB中，清除浏览器数据会丢失 |
| 📤 **如何导出学习数据？** | 在错题本页面点击「导出」按钮 |
| 📱 **换设备后数据还在吗？** | 当前版本数据在本地，换设备需重新学习 |

## 8.2 功能相关

| 问题 | 解答 |
|------|------|
| 🤖 **AI功能收费吗？** | 需要MiniMax API，自行承担API费用 |
| 📝 **错题会自动删除吗？** | 连续答对5次后自动移出错题本 |
| ⏰ **复习时间如何计算？** | 基于艾宾浩斯遗忘曲线+正确率动态调整 |

## 8.3 技术相关

| 问题 | 解答 |
|------|------|
| 🌐 **支持哪些浏览器？** | Chrome、Firefox、Safari、Edge等现代浏览器 |
| 📱 **支持手机吗？** | 支持，建议使用Chrome或Safari |
| ❌ **点击没反应怎么办？** | 等待页面加载完成，或刷新重试 |

## 8.4 快捷键

| 功能 | 键盘快捷键 | 说明 |
|------|------------|------|
| 显示答案 | `空格键` | 复习页面 |
| 认识 | `1` | 复习页面 |
| 不认识 | `2` | 复习页面 |
