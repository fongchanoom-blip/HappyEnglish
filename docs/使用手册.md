## 1. 产品简介

### 1.1 什么是HappyEnglish

HappyEnglish 是一款专为初中生中考英语备考设计的微信小程序，核心理念是"高效备考，轻松提分"。

### 1.2 主要特色

- **500+词汇覆盖**：涵盖中考全部核心词汇
- **艾宾浩斯记忆法**：基于遗忘曲线科学安排复习
- **AI智能分析**：MiniMax大模型提供语境故事和错题分析
- **智能错题本**：自动分类错题，追踪掌握进度

### 1.3 界面导航

## 2. 快速开始

### 2.1 首次使用

1. **访问应用**
   - 打开 HappyEnglish 应用

2. **配置AI服务**（可选）
   - 进入个人中心
   - 设置MiniMax API Key
   - 如不配置，仍可使用基础功能

3. **开始学习**
   - 点击「批量测试」开始词汇学习
   - 或点击「智能复习」复习薄弱词汇

### 2.2 首页功能区

| 区域 | 说明 |
|------|------|
| 学习统计 | 显示今日学习时长、已掌握词汇数 |
| 薄弱词提示 | 显示需要加强复习的词汇数 |
| 快速入口 | 批量测试、智能复习入口 |

## 3. 核心功能

### 3.1 词汇学习流程

```
选择测试模式 → 开始答题 → 查看结果 → 薄弱词复习
     ↓
  答对 → 更新掌握度
     ↓
  答错 → 记录错题 → AI分析
```

### 3.2 词汇状态

| 状态 | 说明 | 颜色 |
|------|------|------|
| 精通 | 连续5次答对 | 绿色 |
| 熟悉 | 正确多于错误 | 蓝色 |
| 薄弱 | 需要加强练习 | 橙色 |
| 陌生 | 错误多于正确 | 红色 |

### 3.3 掌握度计算

- **初始状态**：陌生
- **进步条件**：连续答对
- **退步条件**：答错
- **精通条件**：连续5次答对

## 4. 批量测试

### 4.1 进入批量测试

入口位置：首页「批量测试」按钮

### 4.2 测试设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 测试组数 | 每组30题 | 3组 |
| 测试范围 | 可选全部/已掌握/薄弱 | 全部 |
| 题型 | 选择题（中文选英文） | 默认 |

### 4.3 答题流程

1. **查看题目**
   - 显示英语单词和4个选项
   - 进度指示器显示当前进度

2. **选择答案**
   - 点击选项按钮
   - 选中状态高亮显示

3. **确认答案**
   - 点击「确认」提交答案
   - 立即显示对错

4. **查看解析**
   - 正确：显示「太棒了！」
   - 错误：显示正确答案和简要解析

### 4.4 测试结果

**汇总页面显示**：

| 指标 | 说明 |
|------|------|
| 总题数 | 本次测试总题数 |
| 正确数 | 答对题数 |
| 正确率 | 百分比 |
| 用时 | 本次测试花费时间 |

**分类查看**：
- 全部题目
- 正确题目
- 错误题目（薄弱词）

## 5. 智能复习

### 5.1 复习模式

点击首页「智能复习」进入，提供两种模式：

| 模式 | 说明 |
|------|------|
| 间隔复习 | 基于艾宾浩斯遗忘曲线安排 |
| 智能复习 | 根据薄弱点优先复习 |

### 5.2 复习卡片

复习界面显示单词卡片：

```
┌─────────────────────────────┐
│         abandon            │
│                             │
│      [显示答案] 按钮         │
│                             │
│  ─────────────────────────  │
│  认识    不认识    跳过     │
└─────────────────────────────┘
```

### 5.3 复习操作

| 操作 | 说明 | 效果 |
|------|------|------|
| 显示答案 | 点击显示中文释义 | - |
| 认识 | 已掌握此词 | 更新下次复习时间 |
| 不认识 | 需要加强 | 缩短复习间隔 |
| 跳过 | 暂时跳过 | 不更新状态 |

### 5.4 艾宾浩斯算法

复习间隔计算：

```
第1次复习：1天后
第2次复习：3天后
第3次复习：7天后
第4次复习：14天后
第5次复习：30天后
→ 精通
```

## 6. 错题本

### 6.1 进入错题本

入口位置：首页「错题本」按钮，或复习页面「错题本」tab

### 6.2 错题分类

| 分类 | 说明 |
|------|------|
| 全部 | 显示所有错题记录 |
| 拼写错误 | 单词拼写问题 |
| 词义错误 | 词义理解错误 |
| 发音错误 | 读音混淆 |
| 语法错误 | 语法使用错误 |

### 6.3 错题卡片

每个错题显示：

```
┌─────────────────────────────┐
│      [单词]  [状态标签]     │
│                             │
│  你的答案：________          │
│  正确答案：________          │
│                             │
│  错误类型：[拼写/词义/发音]  │
│  错误次数：3次              │
│  掌握进度：██████░░░ 60%   │
│                             │
│  [查看详情] [开始练习]       │
└─────────────────────────────┘
```

### 6.4 错题详情

点击错题卡片查看详情：

| 内容 | 说明 |
|------|------|
| 单词信息 | 单词、音标、释义 |
| 错误详情 | 你的答案、正确答案 |
| AI分析 | 错误原因分析 |
| 记忆技巧 | 帮助你记住的方法 |
| 练习建议 | 如何加强掌握 |

### 6.5 专项练习

针对同类错题进行强化练习：

1. 选择错误类型
2. 系统从该类型错题中随机抽题
3. 完成练习后更新掌握度

## 7. AI功能

### 7.1 可用AI功能

| 功能 | 说明 |
|------|------|
| 语境故事 | 为单词生成记忆故事 |
| 错题分析 | 分析错误原因和记忆技巧 |
| 学习报告 | 生成个性化学习建议 |

### 7.2 语境故事

**位置**：故事学习页面

**功能**：
- 输入单词或选择待学习词汇
- AI生成150字左右的小故事
- 故事包含单词在语境中的使用

**示例**：
> abandon: 小明站在海边，看着远方的船只渐渐离去，就像他决定___这个城市一样。船只越来越小，最终消失在地平线上...

### 7.3 错题分析

**位置**：错题本详情页

**功能**：
- 分析错误原因
- 提供记忆技巧
- 给出练习建议

### 7.4 API配置

如需使用AI功能，需要配置API Key：

1. 进入个人中心
2. 找到「API设置」
3. 输入MiniMax API Key
4. 保存设置

> 注意：API Key不会在界面上完整显示，仅显示前几位和后几位

## 9. 常见问题

### 9.1 数据相关

**Q: 学习数据保存在哪里？**
A: 保存在浏览器的IndexedDB中，清除浏览器数据会导致学习进度丢失。

**Q: 如何导出学习数据？**
A: 在错题本页面点击「导出」按钮，可导出薄弱词列表。

**Q: 换设备后数据还在吗？**
A: 当前版本数据存储在本地，换设备需要重新学习。后续版本将支持云端同步。

### 9.2 功能相关

**Q: AI功能收费吗？**
A: AI功能需要使用MiniMax API，需自行配置API Key，会产生API调用费用。

**Q: 错题本里的错题会自动删除吗？**
A: 当某个词汇连续答对5次后，会从薄弱词列表中移除。

**Q: 遗忘复习时间是如何计算的？**
A: 基于艾宾浩斯遗忘曲线算法，结合你的答题正确率动态调整。

### 9.3 技术相关

**Q: 支持哪些浏览器？**
A: 支持Chrome、Firefox、Safari、Edge等现代浏览器。

**Q: 为什么有时候点击没反应？**
A: 可能是页面正在加载，请稍等片刻后重试。

**Q: 如何清除所有学习数据？**
A: 在浏览器设置中清除该站点的数据即可。
