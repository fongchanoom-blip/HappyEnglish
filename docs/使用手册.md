# HappyEnglish 使用指南

这是一本专门为初中生准备的中考英语词汇学习指南。APP里内置了1594个核心词汇，足够应对中考英语了。

## 快速上手

第一次打开APP，先看看首页的数据统计，对自己的水平有个大概了解。然后直接点"开始学习"就行，不需要做什么额外准备。

学习过程很简单：看到中文提示就输入英文，看到英文就输入中文。答对了会显示绿色的对勾，答错了显示红色的叉，并给出正确答案。按回车键或点确认按钮提交答案。

每个词汇有四种状态，用不同颜色表示：绿色是精通（连续答对5次），蓝色是熟悉（正确率七成以上），橙色是薄弱（正确率四成到七成），红色是陌生（正确率不到四成）。刚开始大多数词都是红色的，多练几次就慢慢变绿了。

## 词汇测试

测试功能可以一次练30道题，快速检验学习效果。页面顶部可以切换中译英和英译中两种模式。右上角显示连击数，答对越多连击越高。

底部实时统计正确数、错误数和正确率。每答完30道题会显示本轮结果，可以选择再来一轮或者返回首页。

如果想把90道题做完再结束，选择批量测试就行，3组30道题连着做。

## 智能复习

复习功能用的是艾宾浩斯遗忘曲线算法。简单说就是：学完一个词之后，要在恰当的时间复习才能记得牢。太早复习浪费精力，太晚复习早就忘了。

具体什么时候复习，系统会根据你的答题情况自动安排。你只需要在收到复习提醒的时候打开APP完成复习就行。

复习页面先显示单词和音标，自己想一下中文意思，然后点"显示答案"确认。最后选择"认识"或"不认识"告诉系统。键盘上按1表示认识，2表示不认识。

记忆强度会随着每次复习变化。一直选认识的词，记忆强度就会越来越高，需要复习的间隔也越来越长。选不认识的词多了，系统会缩短间隔，让你多练几次。

## 错题本

每次答错的词都会自动记录到错题本里。错题本不只是简单记个错，它还会帮你分析错误原因。

错题按类型分类：拼写错误、词义错误、发音错误、语法错误。点开每个错题可以看到详细的AI分析，包括为什么做错了、怎么记住比较好、跟哪些相似词需要区分。

消灭错题的方法就是专项练习。点开错题详情页，点"开始练习"，系统会专门出这个词的题。连续答对5次，这个错题就会从错题本里移除。

错题本清空了就说明这部分词汇真正掌握了。

## AI功能

APP里有几个地方用到了AI：

语境故事：在某个词汇详情页，系统可以生成一段150字左右的小故事，把这个词融入情节里。配合故事记忆效果比死记硬背好很多。

错题分析：错题本里的每个错题都有AI分析，分析错误原因、给出记忆技巧、区分相似词汇。

学习报告：定期生成学习报告，总结学习数据、指出薄弱点、给出下周建议。

AI功能需要配置MiniMax API才能使用。不配置的话基础学习功能不受影响，只是没有AI分析而已。

## 数据相关

学习数据保存在浏览器本地，清除浏览器数据会丢失。换设备的话数据也不会带过去。后续版本会支持云端同步。

## 成就系统

APP里有几个成就可以解锁：完成第一次测试解锁"初学者"，连续学习7天解锁"坚持者"，掌握100个词汇解锁"词汇大师"，连续50题全对解锁"完美主义"，连击超过20次解锁"连击达人"，消灭50个错题解锁"错题克星"。
